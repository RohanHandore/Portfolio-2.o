# Portfolio PDFs

This repository contains all PDF files for Rohan Handore's portfolio website.

## File Structure

- `cv_pdf/` - Resume and CV files
- `certificates_pdf/` - Professional certificates
- `education_pdf/` - Educational documents
- `experience_pdf/` - Work experience certificates

## Usage

These PDFs are hosted here to provide direct download links for the portfolio website.

## Direct Links Format

```
https://raw.githubusercontent.com/RohanHandore/portfolio-pdfs/main/[folder]/[filename].pdf
```

Example:
```
https://raw.githubusercontent.com/RohanHandore/portfolio-pdfs/main/cv_pdf/Rohan_Handore_CV.pdf
```
